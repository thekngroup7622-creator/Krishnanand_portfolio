by Pitch Map

Objective: How did Dhruv Jurel's Century put Sri Lanka under pressure? Analyze his innings

breakdown by Pitching Length using a 3D Cricket Pitch Map visualization.

Step 1 — Data Collection

Open the Python code in your preferred IDE (VS Code, Cursor, Claude Code, or any other preferred

IDE), and then run the Streamlit application script with the required changes based on the series and

tournament game you are working on.

Refer to Section 3.1 — Configuration & Series Setup for instructions on updating

Step 2 — Data Wrangling: Google Colab + AI Assistant

Once you download the CSV data from the BBB Portal, import it into a new Colab notebook using this

prompt:

"Write clean, modular Python code to import the target dataset from the project working folder

along with all essential analytical libraries and display first 5 rows"

Once the dataset is successfully loaded in your Colab notebook session, follow the below prompt

framework to achieve the derived data structure for this case study:

"Create a data structure for Dhruv Jurel against each Pitching Length, with these metrics: *

Runs → sum of Batter Runs * Balls → count of Balls * Strike Rate → (Runs / Balls) × 100 *

False Shot % * FSIR (False Shot Induced Rate) Use Batter Runs for runs and Balls for balls.

Exclude wides from all calculations. Return the final output grouped by Pitching Length."
